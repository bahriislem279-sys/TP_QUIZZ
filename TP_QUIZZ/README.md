# Quiz Culture & Monuments — Android (Kotlin + XML)

Application Android éducative avec cinq questions illustrées sur les monuments et la culture générale.

## Fonctionnalités
- Une seule activité : `MainActivity`.
- Interface déclarée dans `activity_main.xml` (Design moderne avec cartes et conteneurs épurés, sans Jetpack Compose).
- Cinq questions statiques en Kotlin et cinq illustrations vectorielles locales.
- Trois choix par question, correction immédiate et blocage après réponse.
- Score et progression indépendants.
- Résultat final dans la même activité et bouton **Rejouer**.
- Interface défilante pour les petits écrans.
